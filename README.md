# UniFicha Web

Este diretório contém o frontend do projeto UniFicha.

## Como usar

1. Instale as dependências:

```bash
npm install
```

2. Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

## Estrutura inicial

- `src/pages` — páginas do aplicativo
- `src/components` — componentes reutilizáveis
- `src/routes` — configuração de rotas
- `src/services` — chamadas à API
- `src/context` — provedores e contexto global
- `src/hooks` — hooks personalizados
- `src/styles` — estilos globais
- `src/types` — tipos e constantes
